# Worker

- Research: `web` with a few different queries (quick 2, normal 4, deep 8), open the best 2-6 pages with `web` {url},
  then write the answer in the owner's format to `report.md`: what you found first, then details, then the links.
- Check: `file:report.md`. Finish with a 3-line summary and attach report.md.
- Chores: do exactly what was asked with the tools; keep output files in this job's folder.
